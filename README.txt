# LD Creation — Wall Art Store Prototype

Included:
- Customer storefront
- Product categories
- Cart
- Customer registration/login
- Checkout with address/mobile/payment method
- Order creation
- Admin login/dashboard
- Product add/edit/delete
- Order management and status updates
- Customer list
- Uploaded LD Creation logo

IMPORTANT:
This is a browser-based prototype using localStorage/sessionStorage. It is NOT production-ready for real customer data because authentication and order data are stored in the browser.

For a live deployment, replace the demo storage with a backend/database and secure authentication, plus proper image storage and payment/delivery integrations.


IMAGE UPLOAD:
Admin product form now lets you choose a JPG, PNG or WebP image directly from your computer. The prototype compresses it in the browser and stores it in browser localStorage. For the real GitHub-hosted store, connect cloud storage/database (e.g. Supabase Storage + database) so uploaded images and products are shared with all customers and devices.
